## 实际范围

三个本机命令提供恢复、最后记录查询和明确清理。RESTORE 同意私有暂存，PUBLISH 单独同意发布；来源仍是原本人节点明确保留且当前有效的单提交对象副本。重验原绑定、权限、期限、实际对象与清单，不回源修补、不改保留回执、Task/Run/Operation 或原工作区。

目录从根逐级无链接打开并固定描述符，名字/重叠/归属/展开量复用现有计划规则。写入采用排他普通文件、私有权限、逐对象哈希与实际文件复核；窄 Linux 原语执行 `renameat2(RENAME_NOREPLACE)`，目标被后来创建时连空目录也不覆盖，不退回 copy 或普通 rename。Linux 源码构建增加 `cc` 与 libc 开发头文件要求，运行时不下载或编译；不扩展 macOS/Windows 支持。

独立 FULL-sync 本机 SQLite 保存意图、固定计划、逐文件归属和完成计数。发布返回不确定或成功记录写入失败均保留未知状态，不按“目录存在”补成成功。再次运行相同目标只返回已有记录；重启不自动写入、发布或删除。清理逐条核对本次归属，遇用户新增/编辑/替换/链接材料或日志缺失保留现场，不递归删除或清理已发布目标。
