## 实际交付

| 能力 | 本轮实现与范围 |
| --- | --- |
| 独立执行授权 | 默认仍只有摘要。节点本机 enable-execution 确认工具绝对路径、目录子集、模式、时间/费用限制。只有节点所有者能派发，不把项目成员可见性当执行权 |
| 原任务中执行 | 使用既有 Task/Run，新增 node provider；输入快照、派发、幂等与事件通知在一个事务保存；不会创建另一套节点任务 |
| 接单与启动 | 节点落盘 accepted 后确认接单；服务端一次性启动许可后才尝试启动，实际 spawn 事件才标运行。重复许可不能重复启动 |
| 实际工具进程 | 独立节点复用 Claude CLI / Codex App Server 受限适配器、节点本机 API key、隔离 HOME、只读/文件编辑。未开放 Shell、MCP、额外网络工具或账户兜底 |
| 输出与事件 | 有界状态/文本/终态先写本机日志，服务持久保存后 ACK；丢回应重发同一事件。已知凭证与本机路径脱敏，不上传 raw reasoning 或完整日志 |
| 停止与恢复 | 队列取消不冒充已运行；活动执行收到停止或通信失败即保守请求停止。只有确认终态才能释放占用；未知进程须在节点本机明确核对，不杀磁盘旧 PID、不自动重跑 |
| 目录占用 | 同一 OS 用户的 preview 与独立节点共用持久化目录注册表，根目录或父子目录重叠均互斥；进程状态不明时占用跨重启保留 |
| UI | 在任务内选择本人节点/目录/模式、查看材料与固定工具限额、确认共享输出和费用；执行卡区分派发/接单/许可/实际启动/结束，刷新保留 |
| 撤权 | 撤权后不再接命令或新输出；已绑定派发只允许排空事件序号并提交停止证据，不能借旧凭证恢复执行 |

任务完成与执行完成依然分开。关闭网页不会停止执行；服务或节点重启不会重放付费工作。退出账号不等于撤销设备，仍须明确撤销节点或停用执行。
