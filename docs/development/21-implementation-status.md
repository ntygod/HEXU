## 材料与权限边界

本轮采用**固定材料快照**，而非自动吸收来源后续输出。安排等待时，只有已展示的来源摘录被纳入；要带入最终输出，应在原执行结束后重新配置或再发起接续。目录内容由源执行正常改变，节点启动前仍核对本地目录身份和独占占用；不是 Git 检查点或隐藏会话迁移。

安排以本人节点授权执行，并逐次重查当前项目权限与节点所有权。项目编辑成员可取消待接续以停止后续工作，只读不能取消。退出账号不等于撤销已明确授权的安排；关闭页面也不取消。成员/节点撤权后不能继续派发。

两个模式仍仅监听回环地址。同机本人执行不是跨电脑团队服务。原生 resume/steer/即时输入、他人节点使用授权、完整 AccessGrant、WSS/HTTPS 部署、PostgreSQL、系统凭证存储、Windows、远程 diff/终端/预览、协助/接手/并行仍未完成。

**有效账户真实模型生成仍未联调。** 本轮使用虚构账号/Key、协议替身、真实 HTTP/SQLite/独立进程和临时 Git；不将这些结果称为真实提供方成功。文件工具策略不是 OS 沙箱。
