## 本轮增量

Codex App Server 本机 stdio 协议、初始化/配置核对、API-key 内存认证、模型目录、线程与回合引用、受限读写策略、事件与中断。每项执行独立进程、临时 HOME/CODEX_HOME；不复用用户订阅或个人配置，不把密钥传入 argv、模型上下文或数据库。

已增加 `sourceRunId` 接续动作：同一任务、同一目录，保留未提交修改、来源执行与 Git 基线；任务说明、最近记录和部分变更摘录提供给目标工具。Claude→Codex 和 Codex→Claude 均走各自适配器，不是只改工具图标。重复点击不重复启动，过期来源、其他任务来源和未停止写入被拒绝。

界面新增双工具选择、来源对照、模型目录读取、上下文预览与工具切换后的重新授权。Codex 不显示虚假的美元预算。关闭窗口、改任务状态不等于进程已经停止。
