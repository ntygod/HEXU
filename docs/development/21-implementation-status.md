| 本轮能力 | 实际范围 |
| --- | --- |
| 独立命令行 | connect/start/status/disconnect；独立进程主动连接，不由网页/API 进程托管 |
| 配对与身份 | 网页按项目创建一次性配对码，终端隐藏粘贴并确认账号/项目/本地目录；原子消费，服务仅存凭证哈希 |

| 实际 Git 摘要 | 节点采集暂存、工作区修改、未跟踪条目与冲突数量；不发送路径、文件名、代码、分支名、远程地址或模型密钥 |
| 连接与恢复 | 心跳与连接代次、有界单条未确认 spool、持久化 ACK、重复/跳号校验、断线重连与服务重启握手 |
| 撤销 | 节点主动断开/网页撤销、项目或空间撤权使旧凭证永久失效，重新加入不会复活旧节点 |
| 页面 | 节点卡、目录状态、最近上报、待配对码和撤销界面；支持浅深色和窄屏 |

节点在线仅表示最近有确认的连接通信，**不代表 Run 正在执行，也不代表模型可用**。status 命令只展示本机配置，不能替代实时状态。服务重启后旧连接显示待确认；节点退出或心跳过期不改 Task/Run 状态。

## 本轮没有交付什么

E2b1 **没有团队任务派发、原生进程运行、Run 命令 ACK、跨节点停止或代码接续**。目录摘要不创建 Run，不上传 diff，也不是不可变成果快照。没有 WSS、公网/跨电脑部署、系统凭证存储、自动升级或完整平台支持。

默认 preview 保留已有本机 Claude/Codex 与持久化接续。team-local 保留真实账号/空间/项目协作，新增独立节点摘要，但仍拒绝模拟/原生任务派发和宿主机资源。两个模式都只绑定回环地址。Linux 实测；macOS 未实测；Windows 凭证文件边界尚未支持，CLI 明确拒绝。

有效账户下真实模型生成仍未联调。PostgreSQL、邮件验证/找回密码、项目归档、通用预览、临时协助、跨成员代码接手和并行分支仍按原清单保留未完成。
