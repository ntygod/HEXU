# 03｜账号、空间、项目与首次使用

> D1 · M1—M3 · 关联 HX-F01/F11 · 依赖：01、02。  
> [计划入口](README.md) · [数据/API](18-data-api-catalog.md) · [本地执行器](06-runner-workspaces.md)

## 1. 用户路径

用户建立账号后可以直接开始个人工作，也可以接受团队邀请。没有企业 SSO、内网、外部需求系统或已连接仓库时，仍能建立项目并讨论任务。真正执行代码时才连接本地目录和工具。

首次使用分成独立动作：登录 → 选择个人/团队归属 → 建立任务；连接执行器按需发生。不要把组织架构、预算、模型和项目所有字段塞进一个不可跳过的向导。

## 2. 身份与权限方案

建议复用成熟认证组件，经 `IdentityPort` 提供当前用户、会话与撤销；具体组件在 01 的工程决策中选定。网页采用 HttpOnly、安全 Cookie 与请求来源/CSRF 防护，不能把长期登录令牌放进可被页面脚本随意读取的存储。

空间类型为 personal 或 team；personal 默认只有所有者。团队角色 owner/admin/member 负责管理职责，项目操作另有 view/edit/manage。任务个人可见性与节点权限独立：管理员不因此可读取个人草稿或操作私人电脑。

授权查询集中到服务端 `PermissionService`，列表、搜索、流式事件、附件和直接 ID 访问都走同一范围。前端隐藏按钮只负责体验。移除成员后撤销新访问与后续派发，对已运行进程显示明确处理状态，不声称过去发送的数据能被收回。

## 3. 数据与接口

表组：users/auth sessions 由认证组件管理；spaces、memberships、invitations、projects、project_members、project_repositories、resource_grants、onboarding_preferences 由 HEXU 管理。邀请 token 保存哈希、有效期、目标邮箱或明确的受邀身份，接受时原子消费。

`GET /api/v1/me` 返回账号、空间摘要及可用入口。空间和项目列表按权限过滤。`POST /spaces/:spaceId/invitations`、`POST /invitations/:token/accept`、`POST /spaces/:spaceId/projects` 等详见 18。接口中的 spaceId 与目标对象归属必须相符。

项目仓库信息只保存标准引用、默认分支、运行提示与展示名称，不上传裸凭证。URL 解析只允许支持的协议；服务端不因用户填写 URL 就任意抓取内网地址。扫描和安装仓库依赖是后续独立执行动作。

## 4. 前端页面

登录/恢复访问、空间切换、邀请接受、项目创建、项目成员与仓库卡片。项目创建默认只需名称；目标、描述、仓库以后补。通过关闭状态或小卡片提示“尚未连接开发环境”，不覆盖整个项目页面。

个人空间与团队空间标识清楚。接手和临时协助的有限授权在 12/11 实现，本包先提供通用资源授权端口，不默许被提及者自动成为全项目成员。

## 6. 失败与恢复

邀请过期允许重新邀请，不重用旧 token；重复接受返回已经加入。登录过期保留未发送草稿，重新登录后再次检查权限再发送。最后一个 owner 不能直接离开造成空间无管理者；转移管理由明确操作完成。

项目归档不删除代码和历史。访问被撤销的附件/搜索缓存不得继续显示内容。生产初始化不使用一套全员共享的默认管理员密码。

本包交付账号与项目能力，不建立公司人事档案或绩效分析；内部评估方法仍不进入产品。

名称/说明编辑、manage 权限、严格修订校验、幂等回执、修订历史分页及 W1 设置抽屉已实现。数据库迁移 9 保留已知旧项目快照，不补造作者/时间；更新、历史和项目作用域通知与回执原子提交。冲突保留草稿并明确比较，未知回执复用原标识确认；权限撤销清除设置草稿。项目 ID、任务、成果、成员与节点配置不因编辑改变。

## 03-06 项目归档与执行联动增量

`POST /projects/:id/lifecycle` 接受 archive/restore 与 expectedRevision；归档必须明确 keep/stop。项目管理权前置及事务内校验，项目修订/历史、等待安排暂停、未获许可派发取消、通知和回执原子提交。迁移 10 为同一修订表补充归档状态，不重建业务 ID。

新 Run、原生恢复、等待安排和一次性许可均复核状态；恢复不重放旧工作。已获许可/运行/未知执行在 keep 时保留；stop 仅请求停止有任务操作权的运行，不能以归档回执伪造终止或释放未知锁。归档影响摘要遵守私有任务权限，协作/历史读取保持原边界。日常人工讨论和完成不冻结。

W1 设置抽屉提供归档影响、明确运行选择、冲突和丢失回执确认；项目列表切换已归档，任务入口禁用新执行但保留停止。跨电脑生命周期与正式部署仍未交付，本机切片不提前完成整个远程产品范围。见 [归档使用说明](../engineering/project-archive.md)。
