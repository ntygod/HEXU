# 15｜工作台、团队概览、通知、搜索与费用

> D1 · M3—M4 · 关联 HX-F03/F08/F10/F12 · 依赖：03、04、05、07、14。  
> [计划入口](README.md) · [数据/API](18-data-api-catalog.md)

## 1. 页面目标

我的工作突出继续当前任务、需要回复的事项和最近成果；团队概览突出项目目标、正在推进、阻塞和可查看产物。数据来自实际 Task/Run/Result/讨论，不要求开发者另填一份汇报数据。

工作台不使用成员在线排名、Agent 数量排名和没有依据的完成百分比。可以显示“3 项进行中”，但标明计数是任务状态，不是质量或产能分数。

## 2. 聚合与查询

建立只读查询服务 WorkbenchQuery/ProjectOverview，不再创建可独立编辑的 progress 字段。初始实时 SQL 加合适索引；需要性能优化再用可重建投影，不让缓存成为新的权威来源。

返回 continueTasks、attentionItems、recentResults、projectUpdates、lastSyncedAt。字段携带 deep link、可用动作与来源 ID。存在活动 Run 的 done 任务仍提示执行，不能被默认完成筛选隐藏。

成员列表显示负责事项和请协助入口，不用状态“离开”暗示工作表现。日期按用户时区显示，详情保留绝对时间。

## 3. 注意力与通知

Notification/AttentionItem 从提及、协助、接手、成果反馈和必要授权生成。dedupe key 包含接收者、原因和源对象；同一原因更新同项，不为每个文本 delta 发通知。

已读、已回复、已接受交接是不同状态。已读不自动回答或批准。过期授权不能在旧卡片中继续批准，待处理入口按权威对象重新加载。

支持关注/静音/稍后、站内实时提醒；外部通知在 16 接入。消息只包含允许公开的摘要和权限链接，不能通过通知向无权成员泄露任务标题或敏感文件。

## 4. 全局搜索

搜索覆盖有权的任务、需求、消息、约定和成果，支持类型/项目过滤及稳定分页。先按租户和资源范围筛选，再生成 snippet，不能先检索全库再由前端过滤。

中文输入首先提供标题、编号、明确关键词检索；分词/语义检索可后续替换 SearchPort，不强制新建向量数据库。结果带来源与修订，点击时再次核对权限。删除和撤权需要更新索引并失效缓存。

普通协助受邀者仅能检索明确分享的快照，不因授予一个协助请求而加入整个项目搜索范围。

## 5. 用量与费用

UsageObservation 保存 provider、accountRef、nativeSession/Run、来源、计量范围 incremental/session_total、时间区间和可取得用量；金额使用高精度小数与币种，不用浮点累计金额。

Dedup key 以提供方记录 ID 或稳定事件 ID 为基础。会话累计值需同一身份的 baseline；基线缺失、回退或重置时标记未确定并保留原值，不盲减。模型 token 不是金额，没有价格与账单来源时费用为 null。

CostView 区分 billed/reported/estimated/unknown，汇总说明未计入项，混合币种不直接相加。预算软阈值可以提醒，平台控制后续派发；未报告和已发请求可能产生额外费用，不能宣称绝对零超支。

费用范围可以只给本人或相应管理权限查看，不能自动形成员工排名。

## 7. 不在本包实现的东西

不做产品 A/B 实验平台、收益因果分析、员工工时和效能排行榜。内部团队可以自行评估使用效果；HEXU 只提供自然产生的工作记录与必要导出。

自动生成项目摘要属于可编辑帮助，必须带来源，不编造预计交付日期或“项目已验证通过”。

## 8. 当前15-02工作台任务浏览切片

原工作台最近任务只显示前8项；本轮在同一列表增加逐批展开、收起和当前数量，补足更早的个人/无项目任务入口。仍使用原当前可见Task投影、原顺序与页签/状态筛选，不增加查询服务、通知或搜索能力。交互支持键盘焦点与窄屏，完整验收见[本轮记录](history/2026-10-04-workbench-task-list.md)，15-02保持部分实现。


## 9. 当前15-02我参与的工作台入口

「我参与的」将已有参与关系带到跨项目工作台，不要求记住项目或搜索词。继续卡、关注、成果和任务列表只取当前本人参与的可见Task；缺省参与投影不补造关系，加入/退出后的当前数据更新反映到画面。复用原展开/收起及原活动执行例外，无新通知或后端查询。实际验收见[记录](history/2026-10-04-workbench-participating.md)，15-02仍为部分实现。


## 10. 当前15-02最近列表包括已取消任务

最近任务列表可明确包含当前范围的已取消任务，包括无项目个人任务；不要求记住关键词或进入项目。此选择不改变继续卡、关注、成果或页签计数，原活动执行例外保持。当前列表计数、批次、空态和焦点随显式选择一致，实际验收见[记录](history/2026-10-04-workbench-cancelled-tasks.md)，15-02保持部分实现。


## 11. 当前成果库关键词查找切片

在已有Task命令搜索之外，成果库可按项目与当前Result标题/说明、关联任务标题/编号查找，长说明命中提供有界纯文本片段。筛选保存在URL，项目成果页可带项目进入该入口，再沿原详情打开准确版本链接。

只使用当前已加载且可见的Result投影和原顺序，不检索旧版本、消息/附件或调用新的搜索API。统一多资源SearchPort及其过滤/分页仍未交付，历史全文未提供，语义搜索属于可选后续方向；15-04保持部分实现，见[本轮记录](history/2026-10-04-result-library-search.md)。


## 12. 当前Task搜索分页子条件

原Task搜索超过30项即被截断。本轮沿原GETsearch和当前可见Task源，增加每页30项的游标和继续加载；保留原rowid顺序、标题/说明/编号匹配。游标绑定查询与当前匹配DTO序列，内容/顺序变化后明确重新搜索，不跨变化拼接或承诺历史快照。

验收要求真实超过30项逐页找回、同时间稳定顺序、插入/删除失效后无重复重搜、非法/跨查询游标错误、切词/关闭隔离、键盘/手机与只读数据不变。通过后只闭合Task分页子条件；需求/消息/约定、统一类型/项目过滤及跨资源来源/修订和失效仍欠，15-04整项保持部分实现。实际状态见[本轮记录](history/2026-10-04-task-search-pagination.md)。


## 13. 当前Task级范围与来源辨认

PR68的Task稳定有界分页已验收。本轮进一步提供全部当前可见、当前选定项目或无项目Task范围，在同一既有授权集合内先交集再分页。当前来源、Task修订及有界说明片段帮助区分跨项目同名工作，仍进入原Task详情；不读取历史版本或改变匹配集合。

验收后只闭合Task级项目范围与可辨认命中来源；需求/消息/约定等资源、统一类型过滤及跨资源来源修订/失效仍欠，15-04整体保持部分实现。见[本轮记录](history/2026-10-04-task-search-scope.md)。


## 14. 当前Result进入全局搜索

Task分页、项目/个人范围和来源辨认已由PR68/69验收；本轮将已有当前Result纳入同一全局入口，显式选择Task或Result类型。Result通过当前Task关联后按同一范围筛选，当前成果标题/正文及Task标题/编号沿成果库原独立字段匹配，再保持原顺序和30项有界分页。

当前版本数字、关联来源和正文命中解释结果；打开原成果详情，由既有详情读取处理固定版本，不用数字拼历史ID。本轮只闭合当前Result全局查找子路径，需求/消息/约定等资源及其筛选/来源/分页仍欠，15-04仍部分实现，见[记录](history/2026-10-04-current-result-search.md)。


## 15. 当前15-06成员工作浏览

从工作台选择当前成员后，按负责人或明确参与关系找回当前已加载且可见的Task，保持原顺序、同一任务一次。来源、关系和任务/执行状态分别说明，原Task详情提供后续讨论与成果；成员地址支持刷新与返回，列表逐批呈现。

此子路径不生成工作表现、在线状态或完整工作量，不用Task更新时间伪造同步时间；preview示例与team-local记录按实际来源区分。费用、统一陈旧状态和完整管理视图仍欠，15-06不能整体标为完成。实际实现与验证见[记录](history/2026-10-05-member-work-view.md)。


## 16. 当前项目约定进入全局搜索

约定是15-04明确列出的检索资源。本轮从既有项目内列表补到全局入口，以当前标题/正文匹配、项目范围、30项稳定分页、状态/真实修订/来源和原详情闭合查找路径。包括有效/停用/被替代的当前记录，不把停用内容标为有效，不读取来源讨论或历史全文；个人范围明确不适用。

当前可见项目的约定变更版本只作为已有Workbench只读元数据传递，驱动相关项目搜索重新读取；无关Task变化不打断，项目内其他约定变化可重读。缺元数据不当0，不新增异步探针、身份逻辑或发布/选材命令。最终验收见[记录](history/2026-10-05-current-agreement-search.md)；需求/消息等资源仍欠，15-04整体保持部分实现。
