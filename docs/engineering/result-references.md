# 固定成果版本的报告与发布链接

成果页「报告与发布链接」只属于当前正在看的不可变ResultRevision。选择「登记报告或发布链接」，核对版本和原Task受众，再填标题、稳定地址及可选环境说明，明确登记。普通文字、方案和既有演示版本使用相同人工关联规则；登记不改变成果类型、来源或代码记录。

## 地址与状态

- 标题最多160字符、HTTP/HTTPS完整地址最多2048字符、单行环境说明最多240字符；不支持相对地址或其他协议
- 地址禁止查询参数（包含空`?`）、用户名/密码/空用户信息、控制字符和反斜杠；保留普通章节/行号锚点，但拒绝明显token、签名、认证片段及其有界编码形式。地址经标准URL规范化保存，不静默剥离参数
- 环境是人工说明，不是执行配置；拒绝明显JSON、赋值/令牌内容。校验不是通用秘密检测器，用户仍须自行确认标题、路径、锚点和环境文字没有秘密
- 来源由当前服务身份提供，记录姓名/ID和时间，客户端不能冒充作者；外部可用性与发布状态始终为`unverified`
- 服务不请求该URL，不校验报告结论，不打开端口、执行仓库命令、调用模型或部署。用户明确打开外部链接才在独立窗口导航，使用`noopener noreferrer`

## 固定版本、撤下与记录

发布新成果版本不会带走、继承或覆盖旧关联。关联说明不修改原ResultRevision正文、作者、反馈或代码引用。每条登记的原始内容不可变；错误链接可明确「撤下登记」，原链接不再可点击，仍可展开查看原文字和撤下操作者/时间，再单独登记正确地址。撤下不删除外部页面，不是撤销真实部署，也不改任务完成状态。

登记与撤下各写不可变事件、Task范围outbox及幂等回执，同一事务提交。回执只定位原登记并返回其当前状态；即使原登记后来撤下，确认原登记请求也不会复活链接。相同键不同内容拒绝；撤下以原登记修订和固定成果版本号确认，新的并发撤下需要重新核对。

## 权限与交互

读取使用原Task的当前查看权；登记/撤下使用当前编辑权，权限与版本身份在事务及旧回执之前再次核对。原私有/项目受众不变，空间所有者不会因此看到他人私有内容。归档项目允许人工协作，原执行限制不变。

列表默认20条、最多50条，游标只接受当前版本可访问的登记ID；按固定插入顺序向较早记录翻页。并发新登记不挤动旧页范围；登记后显式返回首屏。撤下的登记仍列出，不因状态变化造成历史丢失。

草稿按当前身份/空间、Task及固定版本保存在Provider内存；应用内往返、关闭保留，放弃、撤权和硬刷新后不恢复。暂时读取错误保留原页/草稿；旧取消读取不覆盖新页。已提交后关闭不取消请求，未知回执只重发原内容、版本和键；晚到响应不能抢走新页面或删除另一个较新请求的草稿。

## 接口与范围

根路径`/api/v1/results/:resultId/versions/:revisionId/references`：

- GET根路径，查询`cursor`与`limit`；GET`/:referenceId`读取单条
- POST根路径接受`action: register`、`expectedResultRevision`、`kind: report|release`、`title`、`url`、可选`environment`；24KiB请求预算与字符限制独立执行
- POST`/:referenceId/lifecycle`接受`action: withdraw`、`expectedResultRevision`、`expectedRevision`，4KiB请求预算
- 写入均要求Idempotency-Key；未知字段拒绝，来源/时间/可用性/发布状态均不能由客户端伪造
