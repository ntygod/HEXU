# 成员的当前工作

从工作台选择「成员工作」，再选当前列表中的成员，即可查看该成员负责或明确参与的当前任务；无需先知道项目或任务关键词。地址为 `/workbench/members/:memberId`，可直接打开、刷新或通过浏览器前进后退回到该成员。页面保留返回全部成员和工作台入口。成员地址只定位当前所选空间中的成员，不携带或切换空间；在新标签页使用时，先用已有空间下拉选择原团队，再打开该成员地址。

## 列表含义

- 仅使用已加载且对查看者可见的Workbench成员与Task，保持原顺序；当前数量不是该成员全部工作量或绩效
- 负责人由ownerUserId确定，参与者只按明确participantUserIds；两种关系可同时标注，同一Task只出现一次
- 包含当前待处理、进行中、完成和取消任务；进入原Task详情查看讨论/成果，列表本身没有状态或执行命令
- 显示项目或个人来源；有项目ID但当前没有对应项目时说明项目当前不可见，不当作个人任务
- Task的最近执行沿原RunBadge呈现，不推断所选成员是执行者；未知执行观察不当作已停止
- 缺省参与信息不补造关系，缺失成员显示当前不可见，不自动切换为本人；preview明确标示示例

首批8项，「显示更多」每次增加8项并将焦点移到第一条新增任务；「收起」保留前8项，焦点回列表标题。数量随当前投影变化，不保存另一份Task副本。页面不会用Task更新时间充当同步时间，也不提供在线排名、费用汇总或统一陈旧状态。
