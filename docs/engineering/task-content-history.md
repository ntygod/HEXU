# Task 工作说明历史

在原任务头部选择“工作说明历史”，可只读查看标题、说明和关注内容的已保存版本。列表按任务修订倒序，每页十条；展开任一记录查看该版全文，点“更早的工作说明”继续。长文字保留换行，不解析为 HTML。

记录区分创建、手工编辑、明确采用内容，以及完成/取消时清除关注内容。操作者是实际发起保存的人；“明确采用内容”沿用原草稿/协助采用流程，不把 AI 建议说成人工原创。详细片段和来源仍在原采用记录中，本入口不额外共享源材料。状态、执行等也使用 Task 修订，因此内容历史编号可以有间隔；相同内容不增加历史记录，也不改变原 PATCH 的修订与回执行为。

新保存到达时提示有新记录，保留当前展开的版本和已加载页；“重新读取历史”回到最新十条。短暂故障保留已读取内容，可重试原页；当前权限拒绝则清空历史，需要关闭后重新打开。任务不再出现在当前工作空间、切换任务/身份/空间时，旧抽屉与未完成读取失效。历史不会存入浏览器持久存储。

旧库迁移只保留当时已有的一份内容，明确显示“操作者未记录”“保存时间未记录”；不根据当前负责人、创建者或任务更新时间猜出作者与保存时间，也不补造之前的编辑过程。演示数据同样按已有快照标记。

`GET /api/v1/tasks/:taskId/content-history` 接受可选 `limit`（1–50，默认10）和 `before`（当前任务实际存在的历史修订号）。未知、重复或非法参数被拒绝；分页先检查当前 Task 阅读权限，再检查位置。空间所有者、协助的有限接收者、历史操作者和旧游标本身都不增加访问权。原任务归档或取消不删除可读历史。

历史与原 Task 更新、outbox 和幂等回执处于同一事务，旧回执不再插入记录。采用内容也在原采用事务内留存快照，失败全部回滚。不可变记录不接受修改或删除。新任务通过原统一插入入口记录初始版本，包括明确从反馈创建的后续任务。

本片只覆盖现有 Task 工作说明。没有历史恢复/回滚按钮，不改变当前执行、运行材料或模型送达；独立 Requirement、多任务关联、附件和更多采用目标仍未实现。相关约束见[项目与任务 harness](../harness/projects-tasks.md)，原编辑行为见[固定基线](task-edit-baseline.md)，验证见[本轮记录](../development/history/2026-10-01-task-content-history.md)。
