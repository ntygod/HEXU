# ADR-0002｜先建立本机原生执行路径

日期：2026-09-25。状态：本轮实现采用，范围为 E1a。

## 选择

在 E0 单用户本地服务内托管 `apps/runner/src` 的执行模块，复用持久化 Task/Run/Result，先打通 Claude Code 文件工具、真实 Git 变更、受管停止和跨次工作记录。原生路径通过本机环境显式启用；默认仍无需账户。

没有把同进程模块宣称为独立执行节点。计划中的身份、PostgreSQL、配对与 WSS 保留为后续工作；不通过开放本地服务规避这些依赖。

## 原因

现有页面与数据已经可运行，而执行仍是 mock。本轮先补最直接的产品缺口，避免同时替换数据库、认证、网络节点和原生协议造成多组未知问题。权限能力先限制到文件工具，减少未接入交互授权时的风险。

采用 bare/restricted + dontAsk；不会为了使用订阅登录而无提示加载仓库 Hooks 或个人配置。只支持当前文档描述的 API key 路径。没有添加新的 npm 依赖或软件许可证。

## 保留的代价

Windows 暂不支持；macOS 尚未实测；只读与修改均没有 Bash，不能运行项目构建和测试；原生 session 恢复和实时输入未做。新执行基于 task/context，不等于原生会话续传。

SQLite 原生工作目录锁跨重启保留，未知进程需本机人工确认；不能靠租约过期直接接管。完整的多节点恢复仍在原计划内。

## 退出与演进

`NativeRuntime`、`LocalWorkspaces`、`runProcess` 与 `ClaudeStream` 边界已分开。独立 Runner 到来后保留协议与 Run 身份，不建立另一套 AI 任务系统。正式存储适配应保持原有任务数据可迁移；底层安全检查不变为产品业务审批。

原生模型调用的真实兼容性由后续有授权的账户联调确认，本轮协议替身测试不替代它。
