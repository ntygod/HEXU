# 固定代码位置的成果反馈

在已有固定成果版本中，打开已共享文件后点「对这个文件提出反馈」。明确选择共同起点文件或此版本所选文件，可选择该侧完整已共享正文的行范围，再填写反馈。发送仍创建原Task的一条消息，不另建评审任务，不修改代码或调度模型。

## 位置与归属

服务按当前成员权限核对Result/ResultRevision和既有不可变差异报告，确认文件、侧与blob匹配；锚点保存原版本关系、文件名、侧、blob、代码引用指纹、差异报告指纹及可选行范围。作者ID由服务当前身份填写，客户端不能代填；旧消息的名称不反推成新的作者ID。

行号与只读差异一致，保留LF/CRLF/CR、空行和末尾无换行。空文件没有虚构第1行。二进制、大文件或预算省略正文的已列出文件可做文件级反馈，不能指定未共享行号；完全未列出的文件不可定位。不从活动目录、仓库或对象副本补读正文。

新版本不会替换旧反馈。反馈消息的「查看固定代码反馈位置」链接回原版本，展开原文件，突出对应范围；未变上下文会展开。复杂diff回退时，仅从同一完整已共享正文展示固定范围摘录。未知反馈ID不会跳到最新版本或其他文件。

## 草稿、回执与权限

- 明确选择代码侧；行范围可不选。新增/删除文件只允许实际存在的一侧
- 返回或Esc只关闭编辑器，未发送草稿在同一身份/空间的Provider内存中保留；另一个文件不会静默接收原草稿
- 尚未确认发送结果时，正文、文件、范围与幂等键固定，只确认原请求；不能改投新版本。关闭不撤回已经发送的请求
- 在同一页面会话内切换版本再回来，可继续原版本的草稿/待确认包。硬刷新、关闭浏览器或身份/空间切换不恢复这份内存，请先确认待决结果；已经保存的反馈继续从原任务历史查看
- 当前Task编辑权限先于旧回执；降权或撤权清除临时编辑，旧键不能绕过权限。短暂读取故障保留已显示的固定历史
- 节点/副本后来不可用，不撤回原来已经明确共享的历史正文；评论这些历史仍要求当前Task权限，不授予任何新的节点读取或执行权限

反馈正文沿用任务消息，不自动复制代码全文。进一步回复关系、转下一轮要求或建立后续任务尚未接入，仍由后续独立动作决定。

## 实现

专用POST `/api/v1/results/:resultId/versions/:revisionId/code-feedback` 只接受正文、文件、侧、预期blob与可选范围。Task、作者、引用/报告指纹从服务派生。消息、原位置和outbox/幂等回执同事务，仍使用现有messages记录；没有新任务/执行/恢复状态或文件存储。
