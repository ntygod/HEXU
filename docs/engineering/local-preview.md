# E0｜本地启动与已知限制

## 准备和运行

推荐 Node 24、npm。根目录 `npm ci` 后，`npm run dev` 打开网页 5173 与 API 4310。修改服务端代码会由 tsc watch 编译，Node watch 重新启动；网页由 Vite 提供。

`npm run build && npm start` 使用 Fastify 提供已构建网页和 API，访问 4310。修改前端后需要重新 build。没有构建产物时，服务返回明确的启动说明，不会伪造网页就绪。

无需模型账户或真实公司资料。示例身份与成员全为虚构。当前实现没有登录页和真正邀请成员；不要以示例姓名切换推断存在账号隔离能力。

## 数据

`.hexu/preview.sqlite` 保存项目、任务、评论、模拟执行和文字成果。首次建立数据库时初始化示例，后续不会覆盖用户记录。删除该文件会丢失本地预览数据；如需备份，请先停止服务，再复制整个 `.hexu` 目录（包含 SQLite 关联文件）。不要在服务运行时只复制主数据库文件。

`npm run test:e2e` 仅清理 `.hexu/e2e`，不清理主预览。单元测试采用内存或系统临时目录。

## 配置

`npm start` 与开发服务读取根目录 `.env`（可选）。支持 HEXU_HOST（仅 127.0.0.1 或 localhost）、HEXU_PORT、HEXU_DATA_DIR。开发默认端口 4310/5173；正式身份未实现前，禁止外网暴露，不要通过代理绕过本地访问限制。

## 如何体验

新建任务后补充说明或评论，刷新确认数据仍在。可以从看板调整待处理／进行中／已完成，也可以在任务或成果页完成与重开。

任务中的“继续”打开模拟面板。选择模拟的 Claude Code 或 Codex 标签以及成功、等待输入、等待授权、失败场景；观察任务与执行状态分开。停止按钮先请求停止再等待适配器确认。

“分享成果”保存真实的文字说明。订单页面是内置虚构预览，支持筛选、分页和导出 CSV，不代表连接了用户代码或业务数据库。

## 限制与排错

- 没有多人身份、PostgreSQL、真实 coding Agent、运行节点、代码 diff 或 shell 终端。
- 协助与并行入口显示不可用，不能用模拟回复代替未来实现。
- 服务重启会结束未完成的模拟执行并留下一条说明；不是恢复原生进程。
- SSE 断线自动重连，页面显示连接状态；服务完全关闭时，已经显示的数据不代表仍然在线。
- 409 表示内容修订已变化：页面会提示刷新，不自动覆盖别人的修改。
- EADDRINUSE 表示端口被占用。先停止旧开发实例，避免启动多个指向同一预览数据库的服务。
- SQLite 为当前开发适配，不承诺正式并发、备份恢复或生产服务等级。

内部团队可自行安排质量和效果评估。以上是运行说明，不是新增的产品审批过程。
