# 本地启动与 preview 模式

本页说明默认示例模式与本地排错。真实账号另见 [team-local](team-local.md)，当前产品能力以 [21](../development/21-implementation-status.md) 为准。

## 准备和启动

使用 Node 24 与 npm。根目录运行：

```bash
npm ci
npm run dev
```

网页在 `http://127.0.0.1:5173`，API 默认 4310。服务端由 TypeScript watch 编译、Node watch 重启，网页由 Vite 提供。构建后运行 `npm run build`、`npm start`，在 `http://127.0.0.1:4310` 使用同来源的网页/API/事件流；改前端后重新 build。

默认 preview 无需模型 Key，使用固定虚构身份/项目，不具备真实账号隔离。模拟执行不调用模型、不读取代码目录；真实账号由独立的 team-local 模式提供，不能以示例姓名推断权限。

## 数据和配置

默认 `.hexu/preview.sqlite` 保存预览的任务、讨论和成果；只首次填充示例，重启不会清空。不要通过删除主库排错。确需手工保存数据时先停止使用它的服务，再处理 SQLite 主文件及关联文件；不要只复制运行中的主数据库。

`.env` 是可选且不入 Git；字段见 [.env.example](../../.env.example) 和 [控制服务启动](../../apps/control/src/main.ts)。默认 HEXU_HOST 为 `127.0.0.1`，也允许 `localhost`，HEXU_PORT 默认 4310；HEXU_DATA_DIR 可显式设置数据目录。team-local 默认使用 `.hexu/team`，不把 preview 数据直接当作团队数据。

当前两种模式均不对外网开放。真实身份已接入也不能通过隧道、反向代理或 `0.0.0.0` 绕过回环限制。

## 体验路径

- 新建任务，补说明/讨论，查看项目看板和文字成果；任务完成不要求报告。
- “继续”中的模拟场景用于观察成功、等待、失败与停止；Task 状态和 Run 状态分别显示。
- 示例订单预览支持筛选和 CSV 导出，只是虚构业务页面，不是用户项目预览。
- 实验性 preview 原生工具需另行显式配置，见 [原生执行](native-execution.md)。真实账号/本人节点用 [team-local](team-local.md)、[配对](runner-node.md)、[执行](runner-execution.md)。

## 排错与验证

| 现象 | 先核对 |
| --- | --- |
| `EADDRINUSE` | 端口与真实进程；不要启动两个指向同一数据库的实例 |
| 页面缺失/旧版本 | 是否完成 build；开发网页 5173 与构建服务 4310 不混淆 |
| 409 | 当前修订已变化，保留草稿并明确比较，不覆盖他人的修改 |
| SSE 断线 | 连接状态及服务是否在线；已有页面内容不代表当前在线 |
| 原生能力不可用 | 平台、显式工具路径/根目录与实际能力；检测通过也不证明 Key 有效 |

`npm run test:e2e` 使用独立可丢弃 `.hexu/e2e`，不清理主预览；测试中不得使用真实用户库/凭证。完整原生/节点测试是 Linux 协议替身验证，macOS 未实测，Windows 原生执行不支持；实际检查只看 21。

服务重启会结束未完成的模拟执行并记录说明；原生旧进程则按保守恢复规则处理，不把模拟重启规则用于释放未知目录锁。SQLite 是本机开发适配，正式远程部署、生产运维和安装分发另行交付。
