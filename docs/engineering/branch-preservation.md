# 方案完整现场移出并保留

此入口把已放弃方案的**完整原目录，连同 `.git` 和所有原内容**移到本人明确指定的全新私有位置。不是永久删除，也不释放磁盘空间；不是复制一份新备份或给保留位置自动授权执行。

当前仅支持 Linux、本机同一文件系统、已登记的普通 `.git` 目录、原本人节点与项目 Task。跨文件系统、linked worktree、特殊/被替换的根或父链不支持。仍要求当前代码完整匹配明确选中的已保留提交；未保存、暂存、未跟踪、忽略内容或未知占用会阻止移动，不因为“保留”而静默放宽保护标准。

## 用户流程

1. 先在同一 Task [明确放弃方案并保留现场](branch-lifecycle.md)。当前选择须先取消/替换；活动/未知 Run 仍显示，如需停止须单独操作并等真实终止。
2. 原节点本人点“移出并保留完整现场”，明确选同一 Node/WorkingCopy 的检查点和有效独立对象副本，核对固定修订并勾选“保留.git和所有内容、不永久删除”。网页只创建请求，不代替本机确认。
3. 在原节点退出已结束工作的同步进程，执行页面给出的命令。将两处带引号占位符换成原节点私有状态目录、**不存在的保留目标绝对路径**；保留目标的父目录须已存在、属于本人、0700，且与原代码同一文件系统。不自动改权限、创建共享目录或覆盖目标。

```bash
npm run runner:branch-preserve -- --preservation REQUEST_ID --state '/path/to/original-branch-state' --target '/path/to/private-preserved/new-directory'
```

4. 本机显示固定方案、原真实目录、新位置和提交。先输入 `STOPPED_AND_PRESERVE REQUEST_ID`，明确原节点、全部子进程/孤儿进程以及其他写入者已经停止；再输入 `PRESERVE REQUEST_ID` 同意本次完整移出。不会向历史 PID 发信号，不借清理前 `CHECK_BRANCH` 当移动授权。
5. 原节点重新核对当前权限、完整独立副本、实际 HEAD/index/文件、原根/Git/父链、受管占用和待发证据。独立窄原语仅做一次 `RENAME_NOREPLACE` 整目录移动；不逐文件复制/删除、不 chmod、不退回普通覆盖 rename。
6. 已核实的新位置、原占用结算与固定完成回执到达后，原 Task 显示“已完整移出并保留”。原路径退出执行用途；原绑定 ID、Task/Run/成果/检查点和节点/材料访问权限继续作历史保留，不把旧路径改成可任意复用的普通工作区。

保留位置不会自动登记新 WorkingCopy，也不授权模型继续。若要在新位置工作，需未来独立登记/授权；当前没有“一键恢复登记”、自动移回或永久清除功能。原保留副本只是所选提交快照；此次保留完整.git靠移动原目录本身，不把单提交副本冒充完整Git历史备份。

## 状态、取消与失败

- 等待本人本机确认：可以在网页另行确认取消。取消请求不移动、删除或回滚文件。
- 本机处置已开始：不能用网页取消撤回。它不证明目录已成功移出。
- 已完整移出并保留：关闭原路径执行登记，原历史/权限保持；报告不是用户之后未编辑/再移动的保证。
- 本次未移出：已确认没有发生移动，或准备在进入移动前中断。只结算本次精确占用，文件保留；新尝试须另行创建新请求。
- 结果未确认：保留原位置、新位置、日志、凭证和原占用。可能已移动；不猜测、不自动回滚、不重放移动，也不提供 force/手动清锁捷径。

重复同一原命令只核对原记录、精确占用收据和待发包，不能更换目标。成功旧收据先于任何后来路径读取；用户后来在原路径创建目录、再移动保留目录或启动另一个已授权写入者，不被旧命令触碰。确认报告的 body/key/sequence/hash 固定，不重新采集来覆盖历史。

移动前明确持久化的“尚未调用移动原语”状态可以记录为未移出；实际意图不确定或移动后验证中断保留占用。未知现场的人工后续处置尚未实现，本轮不会自动把它判成成功。当前撤权可使原报告无法送达；已知本机未移动的精确结算与待发报告分别保留，不删除凭证逃避未确认历史。

## 实现边界

服务用固定请求与不可变两阶段报告，不改原绑定/成果记录，不新建通用备份或第二套调度系统。请求/报告/状态/outbox 原子保存，当前 Task/原本人 Node 权限先于旧回执。移动开始后，副本后来不可用不抹掉已发生的历史完成报告；开始新动作仍须新鲜副本和当前权限。

本机复用原 AgentStorage 及已有整合证据/试应用进程守卫；判别记录保存在既有 branch_binding 中的独立行，原绑定行不改。旧凭证守卫遇未结算行会阻止断开；新解析器还检查固定身份、意图、回执与报告，不能伪造settled。实际目标路径只保留在本机；服务仅收到不透明位置引用与证据哈希。

新原语与旧 restore-publish 分开，旧许可没有扩大。固定两侧父链和原目录描述符、同文件系统/本人私有目录、排他目标、双父目录fsync及移动后核验；rename不是对抗未停止外部写入者的内容条件CAS。原占用按本次claim/root/identity与持久收据原子结算，不从原路径消失或claim缺失推断成功。未知不释放占用；完整目录移动并不宣称跨平台、断电恢复或所有外部文件系统支持。
