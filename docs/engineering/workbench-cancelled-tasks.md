# 在工作台找回已取消任务

工作台「最近任务」新增「包括已取消任务」选择。默认保持原列表；勾选后，在当前「我的工作 / 我参与的 / 团队概览」范围中一并显示已取消任务，包括没有项目的个人任务。任务顺序不变，可逐批展开找到更早的工作，不必先记住关键词。

每次更改选择回到前8项，键盘焦点留在选择框；切换工作台页签重置为默认未勾选和首批。选择只存在当前列表内存中，离开或刷新后恢复默认，不另存偏好。列表显示当前已显示数与所选范围总数；若只有已取消任务，空状态提示勾选查看。

取消任务行显示原状态，并沿现有Task链接打开内容。在详情中使用已有「重新打开」入口继续处理；本片不增加列表内改状态动作，也不把重开Task表示成启动Run。

「包括已取消任务」只影响最近任务列表。继续卡、关注、最近成果和页签旁的活动/关注计数仍按原集合显示；默认列表原本就会保留具有活动或未知执行的取消任务，此例外继续保留。这里只显示当前已加载且可见的Task，不请求额外数据、不扩大负责/参与/团队范围或改变权限。
