# 工作台浏览当前任务

「我的工作」和「团队概览」中的「最近任务」默认显示8项。「显示更多」每次展开接下来的8项，可沿任务链接打开更早的工作，包括没有项目的个人任务。下方显示当前已显示数量和列表总数；已经全部显示时不再提供更多入口。

「收起」回到前8项。切换我的工作/团队概览重新从首批开始；刷新页面也不会保留展开数量。展开后键盘焦点到第一条新任务，收起后回到列表标题。

这里只展开工作台当前已加载的可见任务。顺序、原有页签和取消/活动执行的筛选规则不变，计数表示该列表的Task数量，不表示质量、产能或执行结束。操作不修改任务，也不会发起新执行。
