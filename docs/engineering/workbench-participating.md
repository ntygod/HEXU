# 在工作台查看我参与的任务

工作台增加「我参与的」页签，列出当前可见、参与者中明确包含本人的任务。负责人和参与者是不同关系：自己负责但没有加入参与的任务仍可在「我的工作」找到，不会因此自动进入新页签。其他成员的参与关系也不代替本人参与。

继续卡、需要关注和最近成果随这个任务集合显示。最近任务仍默认8项，每次「显示更多」追加8项，可收起；切换页签从首批重新开始，沿原任务链接进入工作区。没有参与任务时显示加入指引，可在已有项目任务详情的「参与者」中加入。

新页签直接读取当前 Workbench 投影。加入或退出后的新投影更新列表和数量，不保存任务副本或新的持久偏好；刷新/离开后仍回到原默认「我的工作」。已取消任务沿用原例外：只有该任务仍有活动执行或执行观察未知时才继续展示，不能把参与页签当作执行已停止的判断。

没有新增 API、权限规则、通知、任务状态或参与写入入口。只是提供已有协作关系的浏览路径，不会自动加入任务、改派负责人或启动执行。15-02/04-06仍为部分实现，原工作项和实际验收见[进度](../development/21-implementation-status.md)与[本轮记录](../development/history/2026-10-04-workbench-participating.md)。
