# 明确整文件冲突选择

沿用固定ResultRevision、共同起点、原目标提交及完整对象预检。原三方报告始终不可变；本入口只在新的私有候选中记录逐文件决策，不覆盖旧报告、不默认选择来源、不自动文本合并。

## 操作流程

1. 在Task的“整合预检”打开“准备独立试应用”。无冲突新增/修改/删除仍用原勾选；双方均变化的普通文件显示“暂不处理 / 采用来源 / 保留目标”，默认暂不处理。
2. 核对每项删除或新增后果。“采用来源”选整个固定来源版本及Git执行位；来源已删除时表示候选中移除文件。“保留目标”保留目标现有版本，也可能表示维持文件缺失。
3. 确认后生成命令，在本人原节点另行确认创建全新的私有候选。修改选择会清除原确认与命令；状态暂时读取失败保留选择，基线变化必须重新核对，撤权清空内容。
4. 用既有 `runner:integration-trial-diff` 先核对完整对象和候选，再另行确认共享。Task按固定候选ID显示全部决策和实际变化；新候选不会替换正在看的旧候选。
5. 对非空实际变化另行“确认写回此候选”，在原节点指定新私有备份并输入 `STOPPED_AND_APPLY <应用ID>`。所有原目标/对象/候选、当前权限、写锁和备份边界沿用[实际应用](integration-application.md)。

“保留目标”是明确决策，未选择则仍未处理。两者不进入实际应用、备份和[原文件恢复](integration-file-restoration.md)路径。计数分别显示实际采用来源、明确保留目标与未处理冲突；本候选完成不等于全部冲突或代码质量已验收。

## 本机命令与版本

旧无冲突 `--files '["path"]'` 保持原语义。含明确冲突选择时使用版本2的 `--selection`，二者互斥：

```sh
npm run runner:integration-trial -- --operation '<整合ID>' --state '<原节点状态目录>' --target '<全新私有候选绝对目录>' --selection '{"version":2,"kind":"explicit_conflict_choices","selectedPaths":["source-chosen.txt"],"conflictChoices":[{"path":"source-chosen.txt","choice":"take_source"},{"path":"target-kept.txt","choice":"keep_target"}]}'
```

优先使用页面生成并安全转义的命令，替换带引号的目录占位符。`selectedPaths`只含真实采用来源的变化；每个`take_source`必须在其中，每个`keep_target`必须不在其中。实际路径与决策合计最多80项、完整JSON合计48KiB。重复/未知选择、不完整预检和隐含默认拒绝。

私有清单、日志和共享报告显式使用版本2，完整决策参与清单与报告hash；原版本1不升级。旧runner不接受新CLI参数或日志版本，不得手改版本来通过凭证/写入守卫。同一候选或原共享报告不能改决策后重发；应另建私有候选。

## 四种整文件情况

| 原预检 | 采用来源的实际变化 | 保留目标 |
| --- | --- | --- |
| 双方修改 | 用来源完整版本替换当前目标，原目标inode保留到新私有备份 | 保留当前目标版本 |
| 双方独立新增同名文件 | 替换目标已有文件并保留原inode，不当作排他新增 | 保留目标已有文件 |
| 来源删除、目标修改 | 排他移出目标文件到新私有备份，不unlink | 保留目标文件 |
| 来源修改、目标删除 | 在仍缺失的目标路径排他新增来源文件，即使原base不为空 | 维持目标缺失 |

实际变化从目标到最终候选计算，不伪造原三方action或base。完整目标中的未选文件保持；二进制、空文件、普通执行位沿用现有界限。全保留目标可生成并共享0变化候选，保留明确决策；不能创建空应用、获取应用写锁、伪报completed或生成恢复尝试。

## 不支持与目标变化

本切片只处理`both_changed`普通文件。原`path_collision`、文件/目录结构、大小写或NFC碰撞不能靠选择某方绕过；实际候选并集仍重验，存在碰撞则拒绝。文本行/hunk合并、多来源、特殊权限/属性和冲突目录让位仍未交付。

目标HEAD、索引或文件已变化时，原节点拒绝使用旧计划写入。当前“重新核对基线”只是重读原操作，不会重新计算目标。后续专用重新预检流程需要新的明确目标检查点/恢复副本并创建新操作，保留同一固定来源与旧历史；不能自动commit/reset/stash、采集脏现场或迁移旧确认。该入口尚待后续切片。

中断、未知回执、撤权和旧候选重放遵循原应用/候选规则，不重新选择来源、不续写或盲目回滚。完整独立审查仍未完成；当前实际检查见[冲突交付记录](../development/history/2026-09-30-integration-conflict-selection.md)，远端精确head结论见[21](../development/21-implementation-status.md)。HX-DEV-13-05保持部分实现。
