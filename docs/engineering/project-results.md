# 项目成果的有界摘要与固定版本入口

项目原有「项目成果」标签页使用独立只读摘要接口。一个Result对应一行，显示读取时的当前不可变版本、最多160个Unicode字符的正文摘录，以及原Task的标题、短号和当前状态。摘要不包含完整正文、代码、反馈、报告/发布链接或执行要求；需要详情时明确打开原成果版本。

正文含NUL控制字符时，摘要最多保留其前面的有界文字，并用可见替代符标记该位置，后续内容不放进摘要；明确标为已截取。NUL位于160字符之后时仍只返回正常前缀并标记截取。此显示规则不改写原成果正文，也不把省略内容当作完整。

## 版本与范围

「查看此版本」链接固定到卡片显示的revisionId。其他成员随后发布新版，不会把这次已展示的v1入口变成v2；重读摘要时才看到新版本。原版本页面保留既有历史提示、反馈、可选链接和自主切换，列表不迁移这些来源。

同项目的已取消Task仍保留成果历史；取消状态明确属于当前任务，不是成果被删除或已通过检查。已归档项目继续允许读取。各卡另有「打开任务」入口，成果版本和任务当前状态分别说明，不嵌套链接。

## 排序与分页

按Result首次分享的插入顺序从新到旧，后续修订不改变该成果容器在列表中的位置。默认每页20条、最大50条；游标只接受同项目当前可见的Result。并发新增不会挤动已经固定的较早页边界，不提供未经计算的项目总数或质量比例。

浏览器URL保留当前游标和原`tab=results`，刷新与前进/后退回到对应范围；可明确回到第一页或继续查看较早成果。短暂失败显示错误/重试，旧摘要如保留则明确不是最新读取；真实撤权清空，不把错误显示为「没有成果」。

## 权限与数据边界

GET `/api/v1/projects/:projectId/results`仅接受`cursor`、`limit`。当前空间/项目与Task读取权限在数据库投影、分页、游标和任何下一页指示之前应用；项目成员不会因此看见其他人的私有任务。SQL只投影摘要需要的字段；可见成果缺少或错配当前不可变版本时明确报错，不拼造版本、不静默丢掉记录。

这是只读接口，不新增Task、Run、完成事件、成果版本、反馈或分享授权，不调用模型/外部地址。项目完成与实际停止仍走既有命令；没有报告或链接不影响完成。本切片不更改现有`/workbench`的全量成果加载，也不宣称已解决全局传输预算、完整筛选排序或外部同步。
