# 成果页的当前任务执行状态

成果页继续固定正在查看的ResultRevision，并单独显示当前Task的状态与执行记录。完成任务是人的业务操作，不是当前成果版本的验收，不表示模型或进程已经结束；请求停止仍需真实终止确认。

## 来自同一可见快照

当前任务状态、完成/重开的修订基线和执行摘要共同使用现有Workbench权限过滤快照。成果详情自己的轮询只负责固定版本、来源和反馈，不能拿它独立读取的旧Task状态与另一份Run列表拼成假实时状态。

只显示同Task且「处于活动状态，或观察为unknown」的Run，沿用现有领域规则。普通执行、全部方案分支和AI协助都包括在内，不只选择最后一次Run、当前方案或此成果的原来源Run。unknown优先显示待核对；stopping仍是正在停止。旧native记录缺少terminationConfirmed不被臆测为新的unknown记录。

事件连接中断或同步不确定时，明确说明这里是上次读取的记录。当前Task不在可见快照中时不借旧详情恢复写入基线或显示活动信息。没有匹配记录只表示此快照未列出活动/待核对Run，不能称所有进程已停止。

## 有界呈现与现有操作

摘要显示总数及互不重叠的unknown、stopping、其他活动数，每页最多5条，所有匹配记录可前后翻阅；新快照使末页消失时回到仍有效的页。行只使用既有Run标识、工具/提供方、普通/方案/协助分类、时间和状态，不展示要求、正文、上下文或新的私人材料。

「标记完成」「重新打开」仍调用同一个changeStatus与现有完成/停止选择，保留权限、expectedRevision、完成记录和未知进程的原规则。只完成会继续显示运行；请求停止只显示正在停止，实际终态到来后再据快照移出活动列表。完成无需报告，保存新成果不自动重开，重开不自动启动Run。

本切片无新API/表/执行命令/分享权限或模型调用，不改变Workbench现有传输预算，也不改写成果版本、原来源、反馈或链接。
