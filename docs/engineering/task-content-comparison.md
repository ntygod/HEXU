# 对照两版工作说明

在 Task 的“工作说明历史”中展开“对照两个版本”，从已加载记录选择较早、较新两版，然后点“查看两版对照”。默认选择最近两条已读取记录；需要更早版本时，先在历史中加载更早记录。相同或相反次序不能提交对照。

标题、关注文字各自显示是否变化及原文；说明可看带原/新行号与增删标记的行级变化，或切到两版全文。连续未变行可以展开。空白、Unicode及换行来自原始快照；复杂或过多行时明确切到完整正文，全文区域可用键盘滚动。行数只是文字变化，不代表质量、完成度或执行事实。

显示的两侧固定为所选版本。新保存、SSE或重新读取历史不替换当前对照；即使已选旧版不在重读的第一页，它仍留在选择中。选择另一版后，要再次点“查看两版对照”才改变已展示内容。关闭抽屉、切换身份/空间/Task或当前阅读权被撤销后，对照和选择一起清除，不写入浏览器持久存储。

旧库快照继续显示已有内容、未知操作者/保存时间和更早过程未记录，不把它冒充原始创建版本。明确采用内容的记录仍区分采用者与原建议；完整建议来源继续在原采用记录中查看。

这是原 Task 的阅读功能，复用[历史 API](task-content-history.md)的当前权限，没有新读取授权、服务端写入、恢复动作或可应用补丁；独立 Requirement、附件与真正内容采用仍属于各自原工作包。计算复用现有纯文本比较：合计32768字符、2000行、250000矩阵格上限，超过时保留完整两侧内容。见[本轮验证](../development/history/2026-10-01-task-content-comparison.md)。
