# 按项目和关键词查找成果

成果库可按项目和关键词组合查找。关键词匹配当前成果的标题、说明及关联任务的标题/编号；卡片显示关联任务和项目，说明命中时显示附近的有界纯文本片段。项目成果页的「在成果库中查找」入口会预选该项目。

查询基于当前可见成果的当前版本，不检索历史版本的旧文字。成果卡进入原成果详情；需要保留准确版本时，先在详情查看该版本，再使用已有「打开此版本固定链接」。列表中的版本数字不是固定版本地址。

项目和关键词保存在URL，可分享、刷新或通过浏览器前进/返回恢复。「清除成果筛选」只清除这两项条件。归档项目在选择器中明确标识；链接中的项目当前不存在或不可见时显示提示和零结果，不偷偷退回全部成果。没有任何成果、当前项目没有成果和有成果但关键词未匹配分别说明。

成果库保持原有当前可见集合和顺序，包括取消任务中仍可见的成果。项目成果页原列表的范围不改变；通过成果库入口可查找这个项目当前可见的成果。筛选和导航不改Task状态、成果版本、反馈或访问权限，也不发新的搜索接口请求。

关键词最多160个UTF-16代码单元，与输入框上限一致；正文片段最多160个Unicode码点（含省略标记），保留完整字素，长命中可只显示前缀。标题/任务上下文已能解释命中时不重复展示正文片段；HTML字样按文本显示。

这属于14-02/15-04的普通查找切片，历史全文、语义搜索、附件及通用预览仍未交付。实际检查见[本轮记录](../development/history/2026-10-04-result-library-search.md)和[实现进度](../development/21-implementation-status.md)。
