# 全局 Task 搜索分页

搜索与快捷操作仍只检索当前空间可见Task的标题、说明和编号。空输入显示快捷操作；查询保留原去首尾空白、locale小写和字面includes语义，百分号/下划线不是通配符。项目/私有任务、取消与完成状态的既有读取范围不变。

`GET /api/v1/search?q=...` 每页最多30项，返回 `items` 与 `nextCursor`；非空游标可作为下一请求的 `cursor`，结束为null。q保留原160个UTF-16字符上限，先验证原输入再规范化；小写后扩长不改变合法输入预算。已知q/cursor只接受单值，游标有界并采用规范编码；原来忽略的未知查询参数仍忽略，不增加其他检索条件。

游标固定规范化查询、模式、当前用户/空间和边界Task ID，不是授权凭据或冻结搜索结果。每次读取在同一只读快照内核当前权限，按原创建插入顺序向后扫描，先权限后匹配，只保留最多30项及是否存在后续匹配。稀疏查询可能扫描全部候选，不声称已有全文索引或总扫描量上限。

边界Task仍可见并匹配时，普通编辑不移动分页位置；新增较新Task不会混入当前后续页，明确重新搜索才能从顶部查看。边界被删除、撤权或不再匹配时，统一返回409 `INVALID_CURSOR` 并要求重搜，不区分对象存在性，也不静默从第一页追加。其他Task匹配以每次读取的当前内容为准。

页面加载更多失败保留已读行及原游标供明确重试；当前Workbench不再可见、或标题/说明/编号已变化的记录要从显示和匹配依据缓存一起移除，晚回应/后来重授不得复活旧结果。查询变化、关闭/重开、重新搜索和身份/空间变化隔离原请求的成功、失败及finally。页面只在当前Workbench仍可见且三项检索文字与服务端匹配时的内容完全一致时显示当前任务；浏览器不按自己的默认locale重判关键词。检索文字即使修改后仍可能匹配，也要求明确重搜，不根据客户端locale猜测；状态等非检索字段可就地更新。搜索结果不授予新访问权；不会新增Task业务写入、Run或模型调用。
