# Task 完成记录

任务头的“完成记录”读取该Task已经保存的完成、取消和重新打开动作，显示当时任务修订、时间和读取时当前可见成员的显示名。名字不是历史快照；成员已离开或当前不可见时明确显示“操作者当前不可见”，不查询无关用户。数据库若存在未知动作，界面保留原值并标注未知，不推断执行结果。

该入口只读原 `completion_events`。旧Task没有记录就显示为空，不根据当前状态重建历史，不补造操作者、时间、自动规则、原因或完成说明。记录不是当前Task状态，也不证明Run已停止、质量检查通过或代码已发布。

## 读取与权限

`GET /api/v1/tasks/:taskId/completion-history` 接受 `limit`（默认10，1–50）及可选 `before`（同Task已有事件ID）。当前父Task阅读权限先于参数和游标检查；私有Task、跨空间、已撤权与直接ID读取沿用现有规则，不接受历史作者、旧游标或协助摘录作为授权。只读项目成员可以查看。

按 `task_revision DESC, id DESC` 稳定排列，SQL只取本页上限加一条；同修订以事件ID区分，时间相同或倒退不导致翻页遗漏。未知或其他Task游标拒绝并要求重新读取。迁移40仅增加复合查询索引，不改变原事件写入，也不回填数据。

## 页面行为

“更早的记录”追加旧记录；有新事件时保留已读位置并提示，点击“重新读取记录”才替换为最新第一页。短暂失败保留已读内容，分页失败用“重试记录读取”重试原页；SSE记录/权限检查失败用“重试记录检查”仅重查最新记录，不再次追加已成功的页；明确重读取消早先分页和权限探测，旧拒绝不能覆盖新成功。

关闭、Task/身份/空间变化或当前权限拒绝会取消未完成读取。撤权时清除已有记录，关闭后晚成功或晚拒绝不能复活它们；重新获得权限后须重新打开。读取和分页不写Task、Run、事件、回执或执行安排。
