# 固定成果版本的报告与发布链接

在成果详情选定版本后，可在「报告与发布链接」记录对应的报告或发布地址。绑定目标取页面实际已加载的ResultRevision ID；不是当前版本数字，也不会随着新版本自动迁移。固定版本链接可以带同事回到同一版成果。

有父Task读取权限的成员可看当前有效链接；原有编辑权限可添加或移除。每版最多20个有效链接，种类选报告或发布，填写标题和完整HTTP(S)地址，可补环境与来源说明。标题、地址和说明都作为文本显示；链接由用户主动打开，HEXU不会自动抓取、预览或验证外部地址。

记录显示真实记录人/时间、手动来源、未知外部状态和未检查可用性。保存一个报告地址不表示报告通过，发布地址不表示已上线。内嵌账号密码的地址不接受；不要把凭据写入普通说明。移除保留原记录及移除人/时间，页面只展示当前有效链接，尚无移除历史界面。需要修正错误文字时可移除后重新添加。

首次发送时固定版本、原正文和操作标识；提交后若连接中断、结果未知，界面保留该包并通过明确的确认动作重发原请求，不能改包后静默创建第二笔。已经收到成功回执、但列表刷新失败时，只重读列表。重复移除不会增加第二个移除事件。关闭表单不撤回已发出的操作；同一版本页面内可重新打开并确认未结请求。

临时包只保留在当前页面内存。切换成果/版本、离开页面或硬刷新后不会把旧包带到新页面；旧普通响应不能更新新版本的界面。回来后先读取实际列表，再决定是否需要新的操作。引用不改变成果正文、版本、Task完成/取消状态或Run；任务仍可在没有报告和发布链接时完成。

这是14-06的手动关联子路径。自动检查报告、发布集成和通用在线预览仍需后续明确交付。契约见[API目录](../development/18-data-api-catalog.md#14-06-固定版本的手动报告发布链接)，实际检查见[本轮记录](../development/history/2026-10-05-result-reference-links.md)。
