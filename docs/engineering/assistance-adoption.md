# 协助建议的明确局部采用

当前为 `HX-DEV-11-06` 的原任务说明切片，复用真人/AI Assistance 与已有任务说明采用事务。仍是本机模式，不是代码合并、跨电脑接手或真实模型联调。

## 使用

在原任务“协助记录”或有原任务权限的协助独立页中，对同事或 AI 已保存的建议选择“采用此条建议”。从只读正文选择一个或多个片段，点击“添加建议片段”，核对将保留的文字及采用前后任务说明，再明确提交。默认选区为空、方式为追加；可以明确选择替换整个任务说明。自己的追问不是可采用建议。AI 必须已有成功且进程终止已确认的协助 Run；失败、取消、尚未结束的输出不能作为有效建议采用。

鼠标拖选和 Shift/方向键可选局部文本，沿用文字簇移动与 LF 到原始 CRLF/CR 的偏移映射。最多 16 个有序不重叠片段，每段上限 6000 UTF-16 单位，目标说明总长不超过 12000；片段间插入两个换行。字符限制不是 token/模型预算，不静默截断。原建议及未选文字不被删除或改写。

采用前后与来源记录在当前协助的“查看建议采用记录”中查看，含作者、操作者、时间、固定材料、建议全文/哈希、所选范围、任务修订及修改前后正文。分页稳定，不会因为后来修改任务而重算历史。记录仅在原任务和来源仍有读取权限时开放，不能凭协助链接读取其他任务。

## 冲突、权限与撤销

只允许当前任务编辑者采用；发起者身份、项目/空间所有者身份或 `snapshot_reply` 本身都不能替代当前 Task 权限。只有有限协助回复权限的人看不到任务修改前后的内容。已有 Task 编辑权的受邀者按该权限操作，不从“受邀”额外提升权限。私有任务只能由当前私有任务所有者写回本任务。

提交同时核对协助修订、快照哈希、具体回复哈希和目标任务修订。期间有其他回复或目标变更时保留片段，展示最新目标，明确核对后才采用新基线；若建议原文/快照本身变化则必须重新选择。协助依赖的原消息后来变化只提示，固定回复不被自动更新或无条件认定过期无用。

结束协助保留阅读，仍可明确采用。撤销分享或旧授权失效后禁止新采用；已保存的采用记录及其已经修改的任务说明不自动撤回。当前仍有任务编辑及来源读取权限的人可以确认同一旧成功请求，返回原记录，不重复追加或覆盖后来修改。旧接收者撤权再加入不恢复已撤销来源；只读降权禁止旧写回执重放，仍可在有效读取范围内查看历史。

临时读取失败保留当前选区并禁用新写入；401/403/404 清除目标及编辑。失去任务编辑权后关闭采用编辑，恢复权限不复活旧片段。回执未知时固定原参数和请求标识，只能确认原请求，不换目标或模式。页面关闭/刷新、身份或空间切换不持久保存未发送采用编辑；关闭不撤回已发请求。

## 事务与不变边界

迁移 19 增加独立 `assistance_adoptions`，不从旧回复推断任何历史采用。记录不可变，包含完整固定来源快照与回复身份、实际采用范围和任务前后版本。

草稿与协助共用 `packages/db/src/task-description-adoption.ts`。在同一外层事务中写任务说明及修订、暂停 preview 和 node 的等待接续、保存不可变记录、任务范围 outbox 和 ID-only 幂等回执。任一步失败整体回滚；无内容变化不额外修改 Task revision，但仍保存该次明确采用记录。采用事件走原任务范围，不把目标变更信息发送给仅获有限授权的接收者。

采用不改变任务状态/负责人、原始回复、已有模型输入、运行中的 Run、节点授权或未知目录锁，不启动模型、不发送即时输入、不发布项目约定、不写文件。待接续暂停保留原材料和已经发出的停止请求。是否基于新任务说明重新继续由用户另行决定。

## API

沿用 Cookie 身份、当前空间、同源与 `X-Hexu-Client`、写请求 `Idempotency-Key`。源与目标 Task 必须相同。

| 方法 | 路径 | 行为 |
| --- | --- | --- |
| GET | `/tasks/:taskId/assistances/:id/replies/:replyId/adoption-preview` | 当前任务编辑者预览固定回复、快照、目标和当前可采用状态 |
| POST | `/tasks/:taskId/assistances/:id/adoptions` | 严格验证后原子采用，201 返回不可变记录；旧同请求不再写入 |
| GET | `/tasks/:taskId/assistances/:id/adoptions?cursor=&limit=` | 当前任务/来源可读者查看历史；默认 20、最多 50 |

提交仅接受：`replyId, expectedAssistanceRevision, expectedSnapshotHash, expectedReplyHash, expectedTaskRevision, ranges:[{start,end}], mode:'append'|'replace'`。范围是原保存文本的 UTF-16 偏移。服务端自行计算正文、身份、目标和修订；未知字段、跨任务、拆开代理字符/CRLF、重叠/空白/越界片段与超长目标被拒绝。
