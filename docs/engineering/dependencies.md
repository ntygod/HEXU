| 依赖 | 用途 | 上游许可证 |
| --- | --- | --- |
| React / React DOM | 页面与交互 | MIT |
| Vite | 前端开发与构建 | MIT |
| Fastify | 本地 API 与网页服务 | MIT |
| Better Auth 1.7.6 | 实际密码认证、Cookie 会话及撤销 | MIT |
